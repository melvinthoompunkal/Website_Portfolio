Under the hood

Architecture, code, and the reasoning behind each build. Expand a project to dig in. Every snippet comes from the real codebase.

God View real-time event platform ▾

Concurrent streams from GDELT, market feeds, and weather APIs are normalized by async worker pipelines, buffered through Kafka + Redis, and pushed to the browser over WebSockets where a React/WebGL client renders live GeoJSON overlays. A PostGIS spatial layer keeps geographic lookups fast.

Sources→ Kafka→ Async workers→ Redis→ WebSocket→ React / WebGL
Full repository ↗
Graft multi-agent repo analysis ▾

Asking an LLM about an unfamiliar repo hits the context window fast. Graft splits repositories into context-budgeted chunks, runs Claude sub-agents over each window in parallel, then synthesizes findings into a portable blueprint other projects can reuse.

Repo→ Chunker (8k budget)→ Sub-agents parallel→ Synthesizer→ Blueprint bundle
Full repository ↗
StockAnalyzer signal toolkit in pandas ▾

A focused toolkit computing RSI and moving-average indicators straight from Yahoo Finance history. This is the real RSI implementation: vectorized diffs, rolling windows, no external TA library.
